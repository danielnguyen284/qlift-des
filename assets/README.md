# Asset Guide

## Logo

`logo/` contains nine transparent PNG variants extracted from the supplied guideline:

- horizontal, vertical, symbol, favicon, slogan, and reversed-white variants;
- prototype and Claude Design system use only;
- never recolor, crop, stretch, rotate, outline, shadow, gradient-fill, or add effects;
- replace all variants together when approved vector masters arrive.

## Patterns

`patterns/` contains blue and red SVG extractions of the QLIFT geometric pattern. Use them sparingly as framing, transition, watermark, or orientation. Do not turn them into full-page decorative wallpaper.

## Concept images

`concept-images/` contains nine JPEG art-direction scenes. They are generated concepts and must not be presented as completed installations, real products, material evidence, dimensions, specifications, or engineering feasibility.

Use `hero-residential-atrium-concept-v1.jpg` as the required full-bleed Public homepage hero during validation. Label concept imagery `Hình ảnh định hướng` whenever it could be mistaken for real QLIFT work.

## Missing production assets

- Approved vector logo masters.
- Licensed Gilroy webfonts with verified Vietnamese support.
- Approved/self-hosted Montserrat files or an agreed loading policy.
- Approved real product, installation, engineering, team, and project photography.
