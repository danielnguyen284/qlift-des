# Guideline Page References

These JPEGs are visual evidence extracted from the supplied 54-page guideline. They allow Claude Design to inspect composition, logo geometry, color relationships, typography examples, and graphic applications without relying on one large PDF.

| Folder | PDF pages | Purpose |
|---|---:|---|
| `brand-overview/` | 4-5 | Story, tagline, values, personality |
| `logo-system/` | 7-18 | Concept, construction, variants, grid, clear space, sizes, chroma, placement, misuse |
| `color-system/` | 21-27 | Primary/secondary palette, background roles, approved and prohibited combinations |
| `typography/` | 29-35 | Montserrat, Gilroy, hierarchy, case, line height, usage examples |
| `graphic-system/` | 47-52 | Digital application, pattern, image frame, watermark |

Office-identity pages with demo people, phone numbers, addresses, QR codes, and Lorem Ipsum are intentionally excluded. Do not recover or treat those examples as current QLIFT business facts.
